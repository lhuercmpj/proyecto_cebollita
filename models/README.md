# Modelo predictivo

`modelo_cebollita.h` es el encabezado generado por el notebook de la Tarea 2
para ejecutar la red neuronal en la ESP32. `metadata.json` documenta el orden
de entradas, clases y hashes SHA-256 tanto del adjunto original como de la
copia normalizada del repositorio.

La implementacion Python de referencia esta en
`../backend/src/services/prediction_service.py`. No reemplaza al modelo de la
placa: se utiliza para el simulador y para detectar divergencias entre ambas
implementaciones.
